# TODO: согласовать срок действия команд с прошивкой

Backend является источником истины для времени создания и срока действия команды.

## Выбранный контракт

- `expiresAt` сохраняется в формате ISO 8601 и используется в БД, журналах и интерфейсе.
- Для микроконтроллера backend дополнительно возвращает `expiresInMs`, рассчитанное на момент формирования ответа `GET /commands`.
- Прошивка сравнивает `expiresInMs` с локальным `millis()` и не реализует календарный парсер ISO 8601.

Пример:

```json
{
  "commandId": 123,
  "type": "SET_SETPOINT",
  "createdAt": "2026-07-18T10:00:00.000Z",
  "expiresAt": "2026-07-18T10:05:00.000Z",
  "expiresInMs": 184000,
  "payload": {
    "setpointValue": 23.5
  }
}
```

## Критерии приёмки

- Просроченная команда не выдаётся либо отвергается устройством как `expired`.
- Устройство не зависит от RTC и не разбирает ISO 8601.
- `expiresAt` остаётся единым абсолютным значением для БД, журналирования и интерфейса.
- Повторная доставка не продлевает исходный срок команды.
